# Intelligent Agents — source artefacts

Code and raw artefacts for the Intelligent Agents module. This directory is
served as files in the repository, not as site pages; the narrative and the
mapping to learning outcomes lives on
[the module's Artefacts page](../../modules/intelligent-agents/artefacts.md).

Suggested layout:

```
artefacts/intelligent-agents/
├── team-project/     # the team deliverable
├── agent-system/     # the individual agent-based system
└── unit-exercises/   # seminar and unit work
```

Keep each subdirectory self-contained with its own short README stating what it
is and how to run it.
