Each module has its own skills matrix and action plan. This page rolls them up
into one view so that progress across the programme is visible in a single
place, and so that actions carried forward from one module are not lost.

## How the matrix is scored

| Level | Meaning |
| --- | --- |
| 1 — Awareness | I know the concept exists but have not applied it |
| 2 — Novice | Applied with guidance or a worked example to follow |
| 3 — Competent | Applied independently on assessed work |
| 4 — Proficient | Applied reliably, and can adapt the approach to new problems |
| 5 — Expert | Can teach it, and critically evaluate when *not* to use it |
