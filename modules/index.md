## Module structure

Each module page set follows the same seven sections — Overview, Discussions,
Team, Artefacts, Feedback, Skills &amp; PDP, and Reflection — matching the
e-Portfolio requirements set out by the Computing Department.

Modules marked *not started* are placeholders: the learning outcomes are
recorded so that artefacts can be mapped to them as the module runs.
