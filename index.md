## Navigating this portfolio

Every module follows the same structure, so a specific piece of evidence is in
a predictable place:

| Section | What it holds |
| --- | --- |
| Overview | Learning outcomes and an index mapping artefacts to those outcomes |
| Discussions | Collaborative discussion forum posts, peer responses and summaries |
| Team | Team exercise outputs, meeting notes and role allocation |
| Artefacts | Code, designs, diagrams and written work produced in the module |
| Feedback | Feedback received from tutors and peers, and what I did with it |
| Skills & PDP | Professional skills matrix and personal development action plan |
| Reflection | The reflective piece for the module |

A programme-level view of skills development sits on the
